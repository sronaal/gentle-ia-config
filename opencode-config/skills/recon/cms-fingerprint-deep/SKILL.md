## When to Use

- Comprehensive CMS identification beyond basic fingerprinting
- Hunting for specific CMS versions with known CVEs
- Identifying plugins, themes, and extensions
- Pre-exploitation reconnaissance for CMS-specific attacks

## Prerequisites

- whatweb, cmseek, and wappalyzer installed
- Network access to target
- Understanding of common CMS fingerprints

## Procedure

### 1. Basic CMS Detection

```bash
whatweb -v "https://TARGET"
whatweb -a 3 "https://TARGET"  # Aggressive with version detection
whatweb --log-json=/tmp/whatweb.json "https://TARGET"
```

### 2. WordPress Deep Fingerprint

```bash
curl -s "https://TARGET/" | grep -i "wp-content\|wp-includes\|wordpress"
curl -s "https://TARGET/" | grep -oP 'ver=[0-9.]+' | head -5
curl -s "https://TARGET/wp-content/plugins/" | grep -oP 'href="[^"]*/"' | head -20
curl -s "https://TARGET/" | grep -oP 'themes/[^/]*/' | sort -u
```

### 3. Joomla Detection

```bash
curl -sI "https://TARGET/" | grep -i "x-content-encoded-by\|x-generator"
curl -s "https://TARGET/" | grep -oP 'Joomla! [0-9.]+' | head -1
curl -sI "https://TARGET/administrator/" | head -3
```

### 4. Drupal Detection

```bash
curl -sI "https://TARGET/" | grep -i "x-drupal\|x-generator.*drupal"
curl -s "https://TARGET/CHANGELOG.txt" | head -5
curl -s "https://TARGET/modules/" | grep -oP 'href="[^"]*/"' | head -20
```

### 5. Custom CMS Indicators

```bash
curl -s "https://TARGET/" | grep -i "powered by\|built with\|generated by"
for path in "/admin" "/wp-admin" "/administrator" "/login" "/user/login"; do
  STATUS=$(curl -sI "https://TARGET$path" -o /dev/null -w "%{http_code}")
  [ "$STATUS" != "404" ] && echo "CMS Path: $path (HTTP $STATUS)"
done
```

### 6. CMSeek Vulnerability Detection

```bash
cmseek -u "https://TARGET" --follow-redirects
cmseek -u "https://TARGET" --cms wordpress --output /tmp/cmseek.txt
```

### 7. Technology Stack Detection

```bash
curl -sI "https://TARGET/" | grep -i "server\|x-powered-by\|x-aspnet"
curl -s "https://TARGET/" | grep -oP 'src="[^"]*\.js[^"]*"' | head -10
for framework in react vue angular jquery bootstrap lodash; do
  curl -s "https://TARGET/" | grep -qi "$framework" && echo "Framework: $framework"
done
```

## OPSEC Rules

- Fingerprinting is passive reconnaissance — low risk
- Do NOT perform active scans against CMS admin panels
- Document all findings for vulnerability assessment
- Use reasonable request rates

## Verification

```bash
whatweb -v "https://TARGET" | grep -i "cms\|wordpress\|joomla\|drupal"
```

## Pitfalls

- Some CMS installations customize default fingerprints
- CDN/proxy may hide original technology headers
- Version detection may be inaccurate for customized installations
- Some CMS use obfuscated paths
